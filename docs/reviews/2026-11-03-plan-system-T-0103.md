- **P1** follows ruling Q-0047. The part-facts checks (PTC I_max, resistor pulse energy) are in the same package as
  the swap. If no basic or cheap resistor passes, the package stops and goes back to the owner, as the ruling says.
  F4 feeds the panel switches (bilge forced run, navigation lights), so it is safety-relevant: **a competent person
  should review F1/F3/F4 before installation.**
- **P2** comes after P1 because both edit `analog_sw` and the panel-supply budget line.
- **P3** follows ruling Q-0049: rate the HC2 outputs for about 50–100 µF of load capacitance and fit only a short EMC
  slew that stays inside the MOSFET SOA. It also adds the README load guidance. T-0006 and T-0061 are the same problem
  and are covered by that ruling. T-0053 (drop the 21 A option) needs no schematic change: decision 19 is already
  withdrawn, and the 68 k breaker of decision 39 / T-0072 stays. Only the HC2 STATUS note changes.
- **P4** groups the cost levers. T-0090 is the combined finding behind T-0096 (C18) and T-0098 (RIS), so it is done
  by those two changes, not as a third one. In T-0099, the 1 µF → 2.2 µF change at the BTT6050 VS tabs
  (C104–C404) would change a value that confirmed decision 26 names. The brief therefore sends that part back to the
  owner and does only the HC2 and shared positions.
- **P5** is the EMC report's installation text for the README. It comes after P3 so that the two README edits do
  not conflict.

## Decisions (drafted for the owner's rulings)

1. **pdm-hc2, amends 25** (Q-0049, Q-0050, Q-0051): rate HC2 for about 50–100 µF of load capacitance, with a short
   EMC slew inside the SOA, plus the HC2 / 4-ch load split in the README.
2. **system, amends 32** (Q-0047): F1/F3/F4 get a 100 A I_max 60 V PTC plus a series resistor of about
   0.15–0.22 Ω, then F2 gets the same PTC. Safety review required.
3. **system, amends 35** (Q-0048): R3/R4/R7/R8 become 2 k + 2 k 1206 basic C17944, instead of 2.2 k + 2.4 k.

Q-0053 (drop the 21 A option) gets no new row. The owner's withdrawal of decision 19 (2026-11-03) is already in
`docs/decisions.md` and says the same thing: the breaker stays as in decision 39.
