# T-0159: merge near-duplicate BOM lines (scope shared)

Item T-0149, owner ruling "yes" (2026-11-06), decisions 33, 99 and 105. 2026-11-07, unattended.

**Result:** C2, C12, R9 and R10 are swapped on both boards. **C13 stays on C28323** because it fails the DC-bias check, which is the item's own outcome. Values and nets are unchanged.

## What changed

| Ref | Was | Now | Check | Result |
|---|---|---|---|---|
| C2 | C14663 0603 | C307331 0402 | TI SLUSEY1B §7.3.5, §8.2.2.7: 100 nF, X7R/X5R, ≥ 16 V; the part is 100 nF/50 V X7R, 97 nF at 5 V | pass |
| C12 | C52923 0402 | C15849 0603 | VCC2 5 V: 0.70 µF, against 0.60 µF for the old part; CA-IS3050G asks for 0.1 µF (C11) | pass, better than before |
| R9 | C23231 0603 | C36871 0402 | Both ±1 %, ±100 ppm/°C, same maker and series sheet | pass |
| R10 | C31850 0603 | C25768 0402 | As R9 | pass |
| C13 | C28323 0805 | unchanged | See below | swap fails, kept |

**3.3 V setpoint:** tolerance and TCR are identical, so nothing in decision 30 or the budgets depends on this swap. The divider dissipates about 0.1 mW in R9. The stop condition did not trigger.

**C13.** The requirement is C_I 0.33 µF (L78M05 DS0425 rev. 24, p. 8, Table 4 header). It is a test-circuit value, and the only input figure the datasheet gives.

The curve comes from Samsung's Component Library simulation (`weblib.samsungsem.com/mlcc/mlcc-ec.do`, DC Bias graph, Precise model, 25 °C), which is the primary source the facts file named. The catalog and the spec sheet have no curve for this part. These are simulated typical figures, not measurements.

| | C15849 X5R 0603 | C28323 X7R 0805 |
|---|---|---|
| 12 V | 0.31 µF | 0.87 µF |
| 29 V | 0.10 µF (−90 %) | 0.55 µF (−46 %) |
| 29 V × 0.9 tolerance × 0.85 temperature | 0.08 µF, **fails** | 0.42 µF, passes |

C15849 misses 0.33 µF already at 12 V, before tolerance, so this is not a close call.

**R9 on pdm-4ch** (auto decision): R9 is on the shared power-usb sheet, so it changes on both boards, or the shared-sheets gate fails. It is cost-neutral on pdm-4ch: C36871 replaces C23231, one line for one line. Decision 105 already carries this as the planner's note.

## BOM lines

Old codes confirmed gone from both netlists: C14663, C52923, C31850, C23231. C28323 stays, on C13 only.

| Board | Unique parts | Lines fewer | Saving per order at 1.53 USD |
