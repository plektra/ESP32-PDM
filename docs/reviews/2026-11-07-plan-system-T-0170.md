## What the items are about

- **T-0166 and T-0169 are the same problem.** The pdm-4ch J10 socket C577772 has a JLCPCB stock of 0, with a minimum
  order of 18. The two reports raise it with different severity: MINOR in the cost report, MAJOR in the validator
  report. Both give the same fix: re-check the stock when ordering, and have a fallback ready. Neither asks for a
  design change, so the plan makes them one change.
- **T-0169 is less serious than "cannot be assembled" suggests.** Decision 85 says the owner buys and hand-solders
  J10, so JLCPCB assembly does not depend on this stock. What it can hold up is the owner's own purchase: the
  decision 98 sample set before layout, and the parts for the order. The same code is pdm-hc2's J11. That matters
  later, because decision 102 orders pdm-hc2 only after pdm-4ch bring-up.
- **One part of T-0166 is already done.** It says "STATUS says 40", but the pdm-4ch pre-order checklist already
  records "0 / 63 on 2026-11-07, C577772 minimum order 18". The pdm-hc2 checklist gives no number ("stock is thin").
  What is still missing is a named fallback.
- **T-0167 needs no action.** It only confirms the T-0158 saving of about 4.8 $ per board at 5 units ("fix: none
  needed"). It sits in the package so that every item is planned once, with nothing to change.

## Package

**P1 – pdm-4ch J10 socket: stock fallback (T-0166, T-0167, T-0169).** This is documentation and part checks only:
no schematic, footprint or BOM change. The fallback order is:

1. The same part, C577772, from another seller. The validator's fix allows this, and decision 85 makes it possible.
2. C577767 KF2EDGSR-7.62-2P (same maker, 129 in stock).
3. C7422678 DORABO DB3ERC-7.62-2P-GN, only if C577767 fails its checks. It has a different footprint.

Each fallback must pass the same checks:
- it fits the existing `Kefa_KF2EDGSRM-7.62-2P` footprint;
- it mates and locks with the C577752 plug;
- it is rated for at least 16 A;
- it keeps the keying against the 5.08 mm J11.

The result goes on the pdm-4ch pre-order checklist, plus a note for the sync sweep about pdm-hc2 J11. If no fallback
passes without a new plug or a new footprint, the fixer stops and reports, because that would amend decisions 98/104.

## Deferred

None. Re-checking the stock itself happens at order time. The package writes that step into the pre-order checklist,
which already lists it, so no item has to wait.

## Decisions

None. No item has an owner ruling. The fixer's choice of fallback is recorded as an **auto** decision when the
package is applied.
