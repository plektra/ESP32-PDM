# T-0190 – Shared power-usb: C3 to C170101 (cost lever L5)

Date: 2026-11-08 · Scope: shared · Unattended (decision 23, two-way item T-0187)

## What changed and why

**T-0187 (cost lever L5, `docs/reviews/2026-11-07-cost-system-2.md`) – done.**
C3 on the shared `power-usb` sheet (+3V3 to GND at the L1 output), identical on `pdm-4ch` and `pdm-hc2`:

| Field | Before | After |
|---|---|---|
| Value | 2.2uF/50V | 2.2uF/100V |
| LCSC | C377773 | C170101 (Samsung CL31B225KCHSNNE) |
| Footprint | Capacitor_SMD:C_0805_2012Metric | Capacitor_SMD:C_1206_3216Metric |

C170101 is already on both BOMs (C1, C22, C30 and channel caps), so each board drops one unique part (about 1.53 USD
loading fee per order, +0.08 USD per part).

Checks on the part:
- C170101 facts (`docs/part-facts/C170101.md`): 2.2 µF ±10 %, 100 V, X7R, 1206 (3.2 × 1.6 mm), the footprint is
  C_1206_3216Metric. Live JLCPCB stock 2026-11-08: 121 066, so it is in stock.
- U3 LMR51610 output capacitors: the cached file had no output-capacitor section, so I added one with
  `part_facts.py --more` (`docs/part-facts/C22427220.md`, SLUSEY1B §8.2.2.5, Table 8-1). The typical C_OUT for 3.3 V at
  1.1 MHz is 10 µF ceramic. The datasheet gives **no maximum C_OUT and no ESR limit**, because the compensation is
  internal and ESR only sets the ripple. The new C3 has the same nominal value and is still ceramic. An X7R 100 V 1206
  loses less capacitance under DC bias than an X5R 50 V 0805, so the effective capacitance rises a little. I did not
  read a bias curve, so this is only qualitative. No limit is broken, so none of the stop conditions applied.

Documents: design-notes §8.8 (new) and a 2026-11-08 entry in both STATUS.md files (unique −1). On both boards the
2026-11-08 /system line now marks T-0187 as done. ARCHITECTURE and design-notes did not name C3's old part, so there
was nothing to sync there.
