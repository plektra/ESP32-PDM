## Failure-mode note (bilge forced run, safety-relevant)

- The slew does not delay the fast trip of a short while the output is on (PD direct, tSC unchanged).
- A load with more than ≈ 50 µF input capacitance can trip the short-circuit protection at switch-on. The output
  then stays off ≈ 3.8 min and retries, also on the forced-run path. The float switch stays independent
  (invariant 8). Measure the loads on the prototype.
- Switching a channel that just carried 15 A on into a short is outside the calculated SOA. If Q11/Q21 fails short,
  the output cannot be switched off (the body diode of the output-side MOSFET conducts). Only the required external
  breaker (≤ 15–18 A) then clears it.
- **A competent person reviews the bilge outputs before installation.**

## Open points

- Turn-on into a short from a hot channel (after 15 A): margin 0.69–0.89 in a zero-impedance bounding model. No R1/C1
  passes it, and the old hard turn-on is worse in the same model (> 400 A). Real wiring inductance limits it.
  Prototype test added to STATUS. If it fails on the bench, the fix needs a MOSFET or controller change (owner).
- The hot-start ramp margin at 50 µF is only 1.03 on a ±10 % SOA reading. The prototype must confirm the rating
  (Q-0045).

## Suggestions (not done)

- `/validate pdm-hc2 deep`: recheck the §4a.3 SOA method (equivalent rectangle at 30 V, linear derating to 150 °C).
- Firmware could hold off a re-switch-on for some seconds after a 15 A run. That would ease the hot-start-into-short
  corner (`/system firmware`).

```python
"""T-0106 gate-slew sizing for pdm-hc2 (BSC030N08NS5, TPS48110A-Q1). Data: docs/part-facts/C501507.md, C17556513.md."""
import math, itertools, sys
V = 30.0
# SOA Diagram 3, 30 V, Tc 25 C (re-digitised T-0106): t[s] -> I[A]
SOA = [(1e-6, 400.0), (10e-6, 190.0), (100e-6, 16.6), (1e-3, 1.56), (10e-3, 0.44)]
def soa_i(t):
    if t <= SOA[0][0]: return SOA[0][1]
    for (t1, i1), (t2, i2) in zip(SOA, SOA[1:]):
        if t <= t2:
            return math.exp(math.log(i1) + (math.log(i2) - math.log(i1)) * (math.log(t) - math.log(t1)) / (math.log(t2) - math.log(t1)))
    return SOA[-1][1]
# Zth j-c max Diagram 4 (10 us point extrapolated with sqrt(t) from 100 us - assumption)
ZTH = [(1e-6, 0.009), (10e-6, 0.0285), (100e-6, 0.09), (1e-3, 0.29), (10e-3, 0.57), (0.1, 0.9)]
def zth(t):
    if t <= 0: return 0.0
    if t <= ZTH[0][0]: return ZTH[0][1] * math.sqrt(t / ZTH[0][0])
    for (t1, z1), (t2, z2) in zip(ZTH, ZTH[1:]):
        if t <= t2:
            return math.exp(math.log(z1) + (math.log(z2) - math.log(z1)) * (math.log(t) - math.log(t1)) / (math.log(t2) - math.log(t1)))
    return 0.9
# Transfer Diagram 7: Vgs -> Id, envelope of 25 C and 150 C (conservative)
TR25 = [(3.5, 0.5), (4.0, 4.5), (4.5, 35), (5.0, 92), (6.0, 280), (6.5, 400), (7.5, 600)]
TR150 = [(3.0, 0.3), (3.5, 2), (4.0, 18), (4.5, 53), (5.0, 103), (6.0, 249), (6.85, 400), (7.5, 520)]
def interp(tab, x):
    if x <= tab[0][0]: return 0.0 if x < tab[0][0] - 0.5 else tab[0][1] * (x - tab[0][0] + 0.5) / 0.5
    for (x1, y1), (x2, y2) in zip(tab, tab[1:]):
        if x <= x2: return y1 + (y2 - y1) * (x - x1) / (x2 - x1)
    x1, y1 = tab[-2]; x2, y2 = tab[-1]
    return y2 + (y2 - y1) * (x - x2) / (x2 - x1)
def i_d(vg): return max(interp(TR25, vg), interp(TR150, vg))
def vgs_for(i):  # lowest Vgs carrying i (envelope)
    lo, hi = 2.0, 9.0
    for _ in range(50):
        m = (lo + hi) / 2
        if i_d(m) >= i: hi = m
        else: lo = m
    return hi

def pulse_check(ts, ps, k):
    """equivalent rectangle at peak power; returns (E, Ppk, t_eq, Pallow*k, ratio, dTj)"""
    dt = ts[1] - ts[0]
    E = sum(ps) * dt; ppk = max(ps)
    teq = E / ppk
    pal = soa_i(teq) * V * k
    # Zth superposition, evaluate dTj max over time
    dtj = 0.0
    n = len(ps)
    step = max(1, n // 400)
    for j in range(0, n, step):
        tj = ts[j]; s = 0.0; prev = 0.0
        for i in range(0, j + 1, step):
            s += (ps[i] - prev) * zth(tj - ts[i] + dt); prev = ps[i]
        dtj = max(dtj, s)
    return E, ppk, teq, pal, pal / ppk, dtj

def ramp(R1, C1, cload, rload, vbst=12.3, c1tol=0.9):
    """normal turn-on: source follower, slope = (Vbst - Vgs)/(R1*C1)"""
    C1e = C1 * c1tol + 2 * 60e-12
    dt = 0.05e-6; t = 0.0; v = 0.0; ts = []; ps = []; ipk = 0.0
    while v < V - 0.05 and t < 20e-3:
        # current = C dv/dt + v/R ; dv/dt = (vbst - vgs(i))/(R1 C1e)
        i = 0.0
        for _ in range(5):
            s = (vbst - vgs_for(max(i, 0.1))) / (R1 * C1e)
            i = cload * s + v / rload
        ipk = max(ipk, i)
        ps.append((V - v) * i); ts.append(t)
        v += s * dt; t += dt
    return t, ipk, ts, ps

def short(R1, C1, isc, tsc=5e-6, vbst=12.3, c1tol=0.9, cg=9.0e-9):
    """turn-on into a zero-impedance short: gate RC from 0, 30 V across Q11"""
    tau = R1 * (C1 * c1tol + cg)
    dt = 0.01e-6; t = 0.0; ts = []; ps = []; ttrip = None; ipk = 0
    while t < 5e-3:
        vg = vbst * (1 - math.exp(-t / tau)); i = i_d(vg)
        if ttrip is None and i >= isc: ttrip = t
        if ttrip is not None and t > ttrip + tsc: break
        ts.append(t); ps.append(V * i); ipk = max(ipk, i); t += dt
    # trim leading zero-power part
    j = next(k for k, p in enumerate(ps) if p > 1.0)
    return ts[j:], ps[j:], ipk, (ttrip or 0) - ts[j]

if __name__ == '__main__':
    K_COLD = (150 - 47) / 125; K_HOT = (150 - 90) / 125
    R1s = [float(x) for x in sys.argv[1].split(',')] if len(sys.argv) > 1 else [10e3, 22e3, 47e3]
    C1s = [float(x) for x in sys.argv[2].split(',')] if len(sys.argv) > 2 else [1e-9, 2.2e-9, 4.7e-9, 10e-9]
    CL = [float(x) for x in sys.argv[3].split(',')] if len(sys.argv) > 3 else [50e-6, 68e-6, 100e-6]
    print('k_cold %.2f k_hot %.2f' % (K_COLD, K_HOT))
    for R1, C1 in itertools.product(R1s, C1s):
        print('\nR1 %.0fk C1 %.1fn  nominal slope %.2f V/us (Eq.3 0.63*12/(R1C1))' % (R1/1e3, C1*1e9, 7.56/(R1*C1)/1e6))
        for cl in CL:
            T, ipk, ts, ps = ramp(R1, C1, cl, 2.0)
            E, ppk, teq, pal, r, dtj = pulse_check(ts, ps, 1.0)
            Ts, ipks, *_ = ramp(R1, C1, cl, 2.0, vbst=11.0, c1tol=1.1)
            print('  CL %3.0fuF+15A: ramp %.0f-%.0f us, Ipk %.0f A, E %.1f mJ, Ppk %.0f W, teq %.0f us, SOA ratio cold %.2f hot %.2f, dTj %.0f K -> Tj hot %.0f C'
                  % (cl*1e6, T*1e6, Ts*1e6, ipk, E*1e3, ppk, teq*1e6, r*K_COLD, r*K_HOT, dtj, 90+dtj))
        for isc in (71, 91):
            for tsc, vb, tol in ((4e-6, 11.0, 1.1), (5e-6, 12.3, 0.9)):
                ts, ps, ipk, ttrip = short(R1, C1, isc, tsc, vb, tol)
                E, ppk, teq, pal, r, dtj = pulse_check(ts, ps, 1.0)
                print('  short ISC %d A tSC %.0f us Vbst %.1f: trip after %.1f us, Ipk %.0f A, E %.1f mJ, Ppk %.0f W, teq %.1f us, SOA ratio cold %.2f hot %.2f, dTj %.0f K'
                      % (isc, tsc*1e6, vb, ttrip*1e6, ipk, E*1e3, ppk, teq*1e6, r*K_COLD, r*K_HOT, dtj))
```
