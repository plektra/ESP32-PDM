# pdm-4ch fix T-0266: ch4 DEN via off pad R402.1 (T-0264)

Date: 2026-11-13 · unattended pcb-fixer · board pdm-4ch · copper only, no part moved.

## What changed

- `hardware/pdm-4ch/scripts/fixed_routes.py`:
  - the last /DEN leg (B.Cu stub from via 37.30/21.50) now ends at a new via **(38.60, 25.42)**, not at
    (37.60, 24.30) on pad R402.1;
  - a 0.2 mm F.Cu link (one 45° segment) runs from the via to R402.1 (37.71/24.53);
  - `/DEN` is added to `DROP_NETS`.
- Why DROP_NETS: `routing_build.prep` never removes locked copper except DROP_NETS/DROP_GND. Without the entry the
  old on-pad via and stub would have stayed next to the new copper. All 24 /DEN items on the old board came from
  fixed_routes.py (the T-0259 maze pass 2 block), so dropping the net and re-adding it from the script rebuilds it
  exactly (checked by a /DEN copper diff: only the stub, via and link differ).
- The board was rebuilt with `LAND_BEST=1 build_routing.sh` from the HEAD board, so it is again the build output.

## Via position

| item | edge gap from the new via |
|---|---|
| R402.1 (/DEN) | 0.60 mm (≥ 0.5 required) |
| R401.1 (/SW_IN4) | 0.35 mm |
| R403.2 (GND) | 0.94 mm |
| R403.1 (IS) | ≈ 1.0 mm |
| U14 thermal-via field (x 31.4–32.6) | > 5 mm |

FINDING (resolved): the first try at (38.80, 24.95) passed DRC, but it closed the GND-F neck between R402.1 and
R403.1. That cut off a GND-F island at C401.2 (GND-F 37 → 38 islands), and the build stitched it through In2
(GND-In2 18 → 19). Moving the via lower to (38.60, 25.42) with a straight link keeps the neck open, and both pours
are back at their baseline counts.

- After: `kpcb drc` **0 errors, 407 warnings, 46 unconnected, parity 0**. DEN unconnected 0 (was 0). The only

- Pad scan (KiCad Python, via shape to pad shape): no via overlaps any pad of R401/R402/R403/R407. The nearest
  is 0.345 mm (R401.1).
- `heat_budget.py --ambient 40 --currents 4,4,4,4`: Tj 101 °C, unchanged.
- `fix_check.py --role pcb-fixer --scope pdm-4ch`: OK. `fix_check.py --scope pdm-4ch`: OK.

## Safety

No power copper, power pour outline, 16 A path or surge path changed. The change only touches the DEN sense line
of ch4. It removes a risk of an open DEN solder joint, which would lose ch4 fault diagnosis. A competent person
reviews the board before installation.

## Open points

- The boxed-in pads from T-0259 remain (R201.1/R202.1/R301.1/R302.1, the pocket wall to U1, see STATUS.md).
- `/DEN` is now in `DROP_NETS`, so any future /DEN copper must be written in fixed_routes.py. Copper added to the
  board by hand would be dropped on the next build.
