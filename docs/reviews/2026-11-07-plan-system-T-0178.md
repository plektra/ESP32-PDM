  (T-0166, T-0168, T-0177). The owner's ruling keeps the set and makes the order wait if no seller has C577772.
  Write that into both boards' pre-order lists. pdm-hc2 J11 uses the same code, and T-0171 left that open for the
  sweep. Add the README sentence and the battery-plug marking for E21. It is one package because all three items
  edit the same STATUS lines. The scope is `shared`, not `sync`, because a `sync` package may not edit `README.md`.
- **P2 (pdm-hc2, documents only) – HC2 turn-off edge on the pre-compliance scan list** (T-0176). Add the
  R116/R216 0 Ω → 10–22 Ω trial to the decision 28 scan list, with the rule that the short-circuit SOA must be
  recomputed before any value is kept. No value goes into the schematic now. A change would amend decision 25 and is
  the owner's call.

The two packages can run in either order. Both edit `hardware/pdm-hc2/STATUS.md`, in different sections. If both edit
the same paragraph, the result is a Markdown conflict that the agent resolves.

## Deferred

None. The purchase itself (finding C577772 from some seller, and holding the order if none has it) happens at order
time and belongs to the owner. P1 only records the rule.

## Decisions

One row for Q-0068 and Q-0069, amending auto decision 119. It confirms decision 119's "C577772 from another seller
only" and adds the owner's rules: any seller, no flange-less fallback, the order waits. The physical fix for
interchangeable plugs (another set on one board) is not ruled. It stays an open choice for `/system`.

Safety note (E21): if the pdm-4ch battery plug goes into an HC2 output socket, turning channel 2 on is a dead short
outside the calculated SOA. P1 only adds a warning and a marking, so the risk remains until `/system` chooses a
physical fix. A competent person should check the plug marking before installation on a boat that carries both boards.
