## Asked: §7.3.3.2 Open load in OFF (p. 27–28)

| Item | Value | Source |
|---|---|---|
| RPD formula | **None in this datasheet.** §7.3.3.2 gives no RPD formula. It recommends an external pull-up **ROL** (to Vbat via switch SOL); ROL is sized from the leakage currents (Ileakage incl. IL(OFF) and external leakage) and VOL(OFF), but no equation is given | p. 27 §7.3.3.2, Fig. 25 p. 28 |
| RPD role | "An additional RPD resistor can be used to pull VOUT to 0 V. Otherwise, the OUT pin is floating." Also used for short-circuit-to-battery detection (§7.3.4; a resistor RSC_VS to ground, Fig. 27) | p. 27, p. 29 |
| RPD recommended value | 47 kΩ ("Polarization of the output for short circuit to VS detection; improve immunity to electromagnetic noise") | p. 47, Table 11 (BOM, Fig. 52); note on p. 47: simplified example, function must be verified in the application |
| ROL recommended value | 1.5 kΩ ("Ensures polarization of the output during open load in OFF diagnostic") | p. 47, Table 11 |
| IS fault current in open load (OFF) | IIS(FAULT): min 6 / typ 15 / max 40 mA (VIS = VIN = VDSEL = 0 V, VOUT = VS > 10 V, VDEN = 4.5 V; P_7.5.7). Open load in OFF (VOUT > VOL(OFF)) → IS = IIS(FAULT) | p. 30 Table 9; p. 24 (mode table); p. 27 |
| Open-load OFF threshold | Datasheet symbol is **VOL(OFF)**, not "VOUT(OL)": VS − VOL(OFF) = 4 … 6 V (min/max; no typ), VIN = 0 V, VDEN = 4.5 V (P_7.5.1). I.e. open load is detected when VOUT > VS − (4…6 V) | p. 30 Table 9 |
| Open-load ON threshold | **IL(OL)** (symbol as in datasheet): 4 … 25 mA (min/max), VIN = VDEN = 4.5 V; IL below this → IS < IIS(OL) = 8 mA | p. 30 Table 9 (P_7.5.2); p. 27 §7.3.3.1, Fig. 24; Fig. 45 p. 43 |
| Timing | A delay tsIS(FAULT_OL_OFF) must be respected after IN falling edge before an OL-in-OFF diagnosis, else the diagnosis can be wrong | p. 28 §7.3.3.3, Fig. 26 (value: UNVERIFIED, not read) |
| Output leakage (for ROL sizing) | IL(OFF) typ 0.05 / max 0.5 µA (TJ ≤ 85 °C, VIN floating, VOUT = 0); IL(OFF)_150 max 21 µA (TJ = 150 °C) | p. 15, Table 5 (P_5.5.6, P_5.5.8) |
